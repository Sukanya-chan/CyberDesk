# Constraints

## Academic
- Must be explainable in a TYBScCS viva.
- Features map to documented requirements.
- Avoid enterprise complexity without a reason.

## Technical
- Must run on a normal student laptop.
- Core functionality cannot require paid APIs.
- No GPU requirement.
- AI remains optional.

## Security
No arbitrary code execution, malware execution, real-target scanning or unsafe offensive automation.

## Scope
A complete smaller MVP is more important than an enormous incomplete system.
