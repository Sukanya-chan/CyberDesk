# Project Overview

## Product
CyberDesk is a cybersecurity learning and practical-toolkit platform for students.

## Problem
Cybersecurity learning is fragmented across notes, courses, command references, quizzes, labs and tools. CyberDesk connects theory, guided practice, assessment and progress in one structured environment.

## Users
### Student
Learn topics, read lessons, take quizzes, complete safe challenges, search content and track progress.

### Admin/Instructor
Manage learning content, quizzes, challenges and approved platform data.

## Core modules
1. Authentication and roles
2. Learning/content
3. Search
4. Quizzes
5. Safe CTF-style challenges
6. Progress
7. Student dashboard
8. Admin panel
9. Notifications
10. Optional AI assistance

## MVP order
Foundation → Auth → Learning → Dashboard/Progress → Quizzes → Search → Admin → Safe Challenges → Testing/Polish.

## Non-goals
No real-world offensive automation, malware execution, arbitrary code execution, or unnecessary microservices.
