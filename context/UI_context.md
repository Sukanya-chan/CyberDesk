# UI Context

## Direction
Modern cybersecurity learning workstation; technical and intellectual but not a noisy “hacker movie” dashboard.

Dark-first, accessible, clean hierarchy, restrained cyber accents, readable typography, responsive layout.

## Student navigation
Dashboard / Learn / Labs / Quizzes / Progress / Search / Profile

## Admin navigation
Content / Quizzes / Challenges / Users / Settings

Every important view handles loading, empty, validation error, server error and unauthorized states.

Avoid decorative animation that harms usability.
