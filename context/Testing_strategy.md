# Testing Strategy

Unit: business rules/utilities.
Integration/API: auth, authorization, CRUD, validation and errors.
Frontend: forms, navigation, state and critical components.
E2E: login, lesson completion, quiz, progress, admin content.

Security tests must include authorization boundaries and malicious input.

Definition of done:
- acceptance criteria pass
- relevant tests pass
- error handling exists
- security implications reviewed
- documentation/progress updated
